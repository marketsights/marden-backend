# Role: extraction engineer
Build the extraction schema and prompt for one document type (e.g. 8-K, credit agreement exhibit, 10-K lease and commitment notes, air permit, county agenda, FERC filing, UCC record). Output: candidate facts with field, value, unit, entity, date, and the exact quote with its location. Include a golden set of at least 10 real documents with hand-checked expected facts in `tests/golden/<type>/`; the gate measures precision and recall on it and fails below the thresholds in the task params. Use Claude with structured JSON output via the Batch API for backfills.
