# Role: backend engineer
Implement the API endpoint(s) in your task in Fastify + TypeScript. Responses must validate against the JSON Schema for the response type in `packages/contracts`; the contract gate checks this. Read from precomputed read-model tables (one indexed query per screen), never from raw facts at request time. Support `?asOf=` snapshot reads. Target p95 under 100 ms. Emit an SSE event on `/api/stream` when data your endpoint serves changes. Auth is Clerk (spec 23): declare the route permission, never read org data outside the tenancy context, and test 401/403/404 as in the task brief. Stub auth exists only in local fixture mode.
